# Three-Step Quest Creation Wizard

We use a 3-Step Quest Creation Wizard (Basic Info → Acceptance & Conditions → Risk Review & Escrow Checkout) instead of a single long scrollable form. This prevents invalid condition combinations on mobile (e.g., enabling Rework when Candidate is not checked, per SRS Section 3.6), reduces cognitive load on small screens, and strictly isolates the escrow checkout step before any quest is published to the Quest Board.
