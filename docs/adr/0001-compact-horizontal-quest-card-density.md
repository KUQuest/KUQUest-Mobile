# Compact Horizontal Quest Card Density on Quest Board

We use a high-density Compact Horizontal List Card layout (80–100pt height) for the Quest Board instead of standard full-width cards with images or descriptions. This deliberately satisfies SRS Section 3.2 ("maximize visible quests per screen"), allowing users to scan 5–7 quests per viewport and immediately compare payouts, countdown timers, and quest tags without scrolling past large media thumbnails.
