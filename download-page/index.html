How to install

  1. Open this page on your Android phone and tap Download APK.
  2. When Android asks, allow your browser to install unknown apps.
  3. Open the downloaded file and tap Install.

UAT and Staging can be installed side by side.

Compare the SHA-256 with the value shown to confirm the file is intact.
